# De regels

Coaching in de stijl van Tim Grover (*Relentless*). Geen motivatiepraatjes, wel resultaat.

1. **Zelf typen. Geen AI die de code schrijft.** Vragen stellen aan Claude mag, code laten schrijven niet. Wie de code niet zelf schrijft, heeft niets geleerd.
2. **"Weet ik niet" is eerlijk, "ik snap het wel ongeveer" niet.** Een half antwoord verbergt een gat.
3. **Een dag is pas af als de oefeningen af zijn.** Lezen is geen leren.
4. **Elke sessie eindigt met een regel in `LOGBOEK.md`.** Ook als het slecht ging, juist dan.
5. **Geen dag overslaan omdat hij saai is.** Het fundament is saai. Daarom kunnen zo weinig mensen het echt.
6. **Vastgelopen? Eerst 15 minuten zelf proberen, dan pas hulp vragen.** Vastlopen is waar je leert.

> *"Je bent niet waar je wilt zijn. Prima. Dat is het startpunt, geen excuus."*
